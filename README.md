# Ручное тестирование Hexlet Codebattle

Репозиторий тестового проекта по ручному тестированию игровой платформы Hexlet Codebattle. Проект создан для демонстрации навыков QA Engineer в разработке тестовой документации и поиске дефектов.

## О тестируемом проекте
**Hexlet Codebattle** — это веб-платформа для программистов, где пользователи соревнуются в скорости написания кода, решают задачи на различных языках программирования и участвуют в турнирах.

**Область тестирования:**
*   Регистрация и авторизация пользователей через GitHub.
*   Создание игровых комнат, логика подбора соперников и игровой процесс.
*   Работа таймеров, консоли вывода и проверка корректности решений.
*   Турнирные сетки, создание и запуск турниров.
*   Общий чат в лобби и чаты в играх.
